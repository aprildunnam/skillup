Six annotated skills

Not a library. Six files to read closely, argue with, and steal the structure from.

Why six and not sixty

There's already a good library. microsoft.github.io/skills has 175+ skills with one-click install, and it's a better place to get skills than anything this site would build.

These six exist to be read. Each one is annotated with why each section is the way it is, and each one loads into the Skill Forge with a button so you can pull it apart.

vinyl-condition-gradingThe simplest useful skill on the site. Read this one first. used-record-pricingA skill that orchestrates tools instead of duplicating them. open-mic-runsheetTribal knowledge, written down. Ordering rules and a bundled template. consignment-intakeValidation and gatekeeping. The skill that refuses to proceed. lesson-recap-noteTone taught by example, and a rule about what not to write down. shop-site-reviewRepo-scoped, for GitHub Copilot. The only one with a license field.

What to look for

Descriptions

Every one names concrete nouns somebody would type, and every one has a "use when" clause. Compare them and you'll see the pattern.

Boundaries

Five of the six say what they're not for. That one line prevents more misfires than anything else in the file.

Output formats

All six show the shape rather than describing it. That's not a coincidence.

Length

Between 35 and 70 lines. None of them needed to be longer, and the two that were, in their first drafts, got split.
