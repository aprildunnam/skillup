Level 400 / Advanced

What changes at scale

Three skills is a nice afternoon. Forty skills is a system, and systems have failure modes that individual skills don't.

The shift

At three skills, every problem is a writing problem. At forty, most problems are design problems.

With 3 skills With 40 skills
Matching Almost always right Overlap and competition are the default failure
Token cost Irrelevant ~1,600 tokens of descriptions on every single turn
Quality You remember what each does You have no idea if the one you wrote in March still works
Ownership You Somebody who left
Changes Edit and move on Something else breaks and you find out in a month

What's in this level

The token economyWhat every skill costs before it fires, and how to split a fat one. Start here. Skills that drive toolsWhere skills stop being fancy prompts and start being orchestration. Bundled assetsScripts, templates, and reference files, and when one beats another paragraph. Designing a skill setOne skill per job to be done, and what to do when two both think they're relevant. Evaluating skillsA twenty prompt test set and a scorecard that measures two things, not one. Versioning and governanceSource control, review, ownership, and the permission model per platform.
