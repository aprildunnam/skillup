A course site for Agent Skills

Skills are the easiest thing you're not using yet.

A skill is a folder with a markdown file in it that teaches your agent how your team does a thing. That's it. This site takes you from "what even is that" to running your own skill library, and gives you a lab to build one badly and find out why.

Four levels, one file format

Every level ends with something you can do, not something you've read. Start at 100 even if you've built agents before, because the loading model in Level 100 is what makes the rest click.

LEVEL 100FoundationsWhat a skill is, how the agent decides to use it, and how it's different from instructions, knowledge, and tools. LEVEL 200AuthoringWriting one that actually fires. Descriptions, body structure, the five ways skills fail, and how to fix each one. LEVEL 300ShippingThe same file installed in Copilot Studio, M365 Copilot, SharePoint, GitHub Copilot, and VS Code. LEVEL 400AdvancedToken economy, skills that drive tools, bundled assets, designing a skill set, and evaluating whether any of it works.

Everything here happens at one record shop

April's Acoustic Cafe

Used vinyl out front, a six seat espresso bar in the middle, three lesson rooms in the back, and an open mic every Thursday. Eleven staff, one overloaded owner, and a pile of repeatable work nobody has written down.

Every example on this site is a real job somebody at the shop actually does. That's on purpose. Skills are boring in the abstract and obvious the second you attach them to a person with a task.

This is not a skill library

Go get skills here

microsoft.github.io/skills is a browsable explorer with 175+ skills, custom agents, and MCP configurations, installable with a single npx skills add microsoft/skills. Source at github.com/microsoft/skills.

SkillUp teaches you to read those, judge them, fix them, and write your own. The six samples here exist to be studied line by line, not installed.

SkillUp is a teaching site. Every example runs on April's Acoustic Cafe, a record shop that doesn't exist.
