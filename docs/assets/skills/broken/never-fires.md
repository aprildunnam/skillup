# Open mic run sheet

This skill helps with building the run sheet for the open mic night. It
should be used when a run sheet is needed. The run sheet should be
professional and well organized, and should reflect the friendly
character of the shop while remaining accurate and complete.

Consider the various acts that have signed up and order them
appropriately based on the usual considerations. Make sure the sound
check is scheduled and that everyone knows when they are playing.

The output should be clear and easy to read.
