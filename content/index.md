# Skills are the <em>easiest</em> thing you're not using yet.

<p class="lede">A skill is a folder with a markdown file in it that teaches your agent how your team does a thing. That's it. This site takes you from "what even is that" to running your own skill library, and gives you a lab to build one badly and find out why.</p>

## Four levels, one file format

<p class="section-lede">Every level ends with something you can do, not something you've read. Start at 100 even if you've built agents before, because the loading model in Level 100 is what makes the rest click.</p>

## Everything here happens at one record shop

<div class="shopcard">
<h3>April's Acoustic Cafe</h3>
<p>Used vinyl out front, a six seat espresso bar in the middle, three lesson rooms in the back, and an open mic every Thursday. Eleven staff, one overloaded owner, and a pile of repeatable work nobody has written down.</p>
<p>Every example on this site is a real job somebody at the shop actually does. That's on purpose. Skills are boring in the abstract and obvious the second you attach them to a person with a task.</p>

## This is not a skill library

<p class="section-lede">There's already a good one, and it's better than anything this site would build.</p>

<div class="note">
<p class="eyebrow">Go get skills here</p>
<p><a href="https://microsoft.github.io/skills">microsoft.github.io/skills</a> is a browsable explorer with 175+ skills, custom agents, and MCP configurations, installable with a single <code>npx skills add microsoft/skills</code>. Source at <a href="https://github.com/microsoft/skills">github.com/microsoft/skills</a>.</p>
<p>SkillUp teaches you to read those, judge them, fix them, and write your own. The <a href="/skillup/samples/">six samples here</a> exist to be studied line by line, not installed.</p>
